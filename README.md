# 150 Real-Life AI Projects Through My Eyes (Class 8 Student Edition)

Simple, interactive web pages for 150 student AI project ideas from rural Telangana. Each page works on a phone, reads aloud in Telugu/English, and shows how a Class 8 student can build it with free tools (Teachable Machine, PictoBlox/Scratch, Gemini, Google Lens, Canva).

Content lives in `data/NNN.json`; run `python build.py` to regenerate pages and `node check.js` to test widgets.
